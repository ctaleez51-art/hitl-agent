# 사람이 승인하는 인적공제 상담 에이전트

2025년 귀속 인적공제 질문에 근거 문서만으로 답하는 에이전트에, **고객에게 답을 보내기 직전** 사람이 승인하는 단계(HITL)를 붙였습니다. 승인 기준에 걸린 답만 담당자가 보고, 나머지는 자동으로 발송됩니다.

모두의연구소 「9. 사람이 승인하는 에이전트 만들기」 프로젝트 과제입니다. 라우팅 과제 [tax-routing-agent](https://github.com/ctaleez51-art/tax-routing-agent)의 파이프라인(판정 → 근거 조회 → 답변 → 검증)을 이어서 썼습니다.

**보고서: [REPORT.md](REPORT.md)**

```
질문 → 판정 → 근거 조회 → 답변 → 검증 → 승인 기준 계산 ─(안 걸림)→ 자동 발송
                                              └(걸림)→ 멈춤 → 담당자 답
                                                          승인 / 수정 후 승인 → 발송
                                                          반려 → 발송 안 함 (상담원이 직접 처리)
                                                          다시 판정 → 지시를 붙여 다시 답변 → 다시 멈춤
```

## 승인 기준

하나라도 걸리면 멈춥니다. 모두 코드로 계산합니다([criteria.py](criteria.py)).

| 기준 | 대비하는 위험 |
|---|---|
| 두 카테고리에 걸친 질문 | 두 규칙을 합쳐 판단하다가 요건 하나를 빠뜨림 |
| 질문이나 답변에 '장애'가 들어감 | 장애인증명서 같은 서류 요건을 빠뜨림 |
| 질문에 금액이 들어감 | 금액 비교를 틀리거나 빼먹어 '공제 가능'과 '불가'가 뒤바뀜 |
| 질문에 2025년이 아닌 연도(작년·내년 포함)가 들어감 | 어느 해 연말정산에 적용되는지 혼동함 |
| 담당자가 다시 판정을 요청해 새로 쓴 답 | 새로 쓴 답을 아무도 확인하지 않고 내보냄 |

멈춘 건은 `store/checkpoints.sqlite`에 저장되어 프로그램을 껐다 켜도 이어서 처리됩니다. 3일 넘게 대기한 건은 자동 반려되어 상담원이 직접 처리합니다.

## 결과 요약

질문 34건(라우팅 과제 22건 + 이번에 더한 어려운 질문 12건). 판정 `gpt-5.6-luna`, 답변·채점 `gpt-5.6-terra`.

| | 건수 |
|---|---|
| 답하지 않고 상담원에게 넘김 | 5 |
| 답변까지 간 건 | 29 |
| └ 승인 기준에 걸려 멈춤 | 14 |
| └ 자동 발송 | 15 |

답변 29건 중 채점에서 틀린 답은 5건이었고, 5건 모두 승인 기준에 걸려 멈췄습니다(놓침 0건, 헛멈춤 9건). 기준 후보별 비교는 [results/criteria.md](results/criteria.md), 건별 결과는 [results/summary.md](results/summary.md)에 있습니다.

## 실행

```
pip install -r requirements.txt
```

이 폴더에 `.env` 파일을 만들고 `OPENAI_API_KEY=...`를 넣습니다. (`.env`는 저장소에 올리지 않습니다.)

질문 34건을 넣습니다. 승인 기준에 걸린 건은 멈춘 채로 저장됩니다.

```
python run_batch.py
```

기준 후보별 개입·놓침·헛멈춤을 셉니다. 담당자가 답을 주기 전에 실행합니다.

```
python validate.py
```

데모 화면에서 멈춘 건을 열어 답을 줍니다. 왼쪽에서 새 질문을 넣을 수도 있습니다.

```
streamlit run app.py
```

처리 결과를 `results/summary.md`로 집계합니다.

```
python run_batch.py --summary
```
